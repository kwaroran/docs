# Desktop

RisuAI is available as a desktop application for Windows, macOS, and Linux.

## Download

Download the latest version from the [GitHub Releases](https://github.com/kwaroran/RisuAI/releases) page.

### Windows

1. Download the `.exe` installer
2. Run the installer
3. Follow the installation wizard

### macOS

1. Download the `.dmg` file
2. Open the DMG file
3. Drag RisuAI to your Applications folder

### Linux

1. Download the `.AppImage` or `.deb` file
2. For AppImage: Make it executable and run
   ```bash
   chmod +x RisuAI-*.AppImage
   ./RisuAI-*.AppImage
   ```
3. For Debian/Ubuntu: Install using dpkg
   ```bash
   sudo dpkg -i RisuAI-*.deb
   ```

## Advantages of Desktop Version

- Offline access to your data
- Better performance
- Native system integration

# Installation

Welcome to the RisuAI installation guide. Here you can find instructions on how to install and set up RisuAI on various platforms.

## Platforms

RisuAI is available on multiple platforms:

- **Web**: Use RisuAI directly in your browser at [risuai.net](https://risuai.net)
- **Desktop**: Download the desktop application for Windows, macOS, or Linux
- **Node.js**: Run RisuAI locally using Node.js

Select your platform from the sidebar to get started.

# DemonRoute

[DemonRoute](https://demonroute.com/) is a prepaid, OpenAI-compatible gateway to open-weight and uncensored models. RisuAI creators can connect through a custom API rather than needing a dedicated provider integration.

Use DemonRoute's [configuration instructions](https://demonroute.com/integrations) for its endpoint and key setup. The API base URL is `https://api.demonroute.com/v1`; for a Custom API field that expects a full chat-completions URL, use `https://api.demonroute.com/v1/chat/completions`. Enter your DemonRoute key in the API Key field and copy an exact model ID from the [current model catalog](https://demonroute.com/models).

[Create an anonymous account](https://demonroute.com/login?door=anonymous): a crypto deposit is required before API use; see [Pricing](https://demonroute.com/pricing) for the current minimum and model rates. Anonymous accounts cannot be recovered if you lose the key. Save it securely before funding the account.

DemonRoute states that it does not log IP addresses. Read its [Privacy Policy](https://demonroute.com/privacy) for what it collects and retains; this is not an end-to-end anonymity guarantee. Model responses and availability vary by model and upstream provider.
